# 🌐 Frontend Service Rules (`apps/web` - GEMINI.md)

- Use React 19, Vite 6, Tailwind CSS v4, and TanStack Query v5.
- Modularize by feature in `src/features/<feature-name>`.
- Use `<DataTableTemplate />` for tables and `<SearchInput />` for debounced search.
- Use direct-to-S3 uploaders (`<ImageUploadInput />`, `<ResumeUploadInput />`).
